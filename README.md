# Pet Rescue

Working concept: **Pet Rescue: Borrow & Escape**, a proposed YouTube Playables game.

- [Game brief](docs/PET_RESCUE_BRIEF.md)
- [Textless gameplay requirements](docs/TEXTLESS_GAMEPLAY.md)

The core game is intended to work without reading and with one finger at a time. Rescued companions provide useful abilities that change subsequent rescues.

**Status:** planning documents only; no playable implementation, completed full build contract, test results or publication. Graphics remain unspecified. Exact ad cadence is not settled by these documents; preserve user-approved monetization decisions.
